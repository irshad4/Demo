# Snake Game Instructions

## Starting the Development Server
1. Open your terminal.
2. Navigate to the project directory:
   ```
   cd path/to/Demo
   ```
3. Start the server:
   ```
   npm start
   ```

## Navigation
- Open your web browser.
- Navigate to `http://localhost:3000` (or the port specified in your server).

## Verification Checklist
- Ensure the game loads properly.
- Check if you can start a new game.
- Verify that the controls function as expected.
